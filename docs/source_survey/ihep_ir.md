# 数据源摸排：中科院高能物理研究所机构知识库（IHEP OpenIR）

摸排日期：2026-10-14。原则：礼貌访问，不绕过任何验证码/反爬措施。

## 平台

- 地址：https://ir.ihep.ac.cn/
- 平台：CSpace（中科院机构知识库平台，JSPUI 风格，路径与 DSpace 5/6 类似）
- 馆藏结构：community-list 可见"学位论文"专题合集（高能所物理学院相关合集约 3210 条），另有"博士后出站报告"等

## 可达性实测

| 端点 | 结果 |
|---|---|
| `/` 首页 | 200，可访问 |
| `/community-list` | 200，完整合集目录（含各合集条目数） |
| `/feed/rss_2.0/site`、`/feed/atom_1.0/site` | 200，仅最近 10 条新增，字段=题名+作者+日期，**无导师字段** |
| `/oai/request?verb=Identify` 及 /oai、/OAI、/oai-pmh 等常见变体 | 全部 404，**OAI-PMH 未启用** |
| `/rest/status`、`/rest/handle/...` | 404，REST API 未启用 |
| `/simple-search?query=...` | 200 但返回**滑动验证码**页面 |
| `/handle/311005/<id>?mode=full` 详情页 | 滑动验证码 |

## 结论

**不可自动采集。** 搜索、浏览、详情页全部位于滑动验证码之后；无 OAI-PMH、无 REST；RSS 无导师字段且只有最近 10 条。
不绕过验证码（反爬红线），因此 IHEP IR 只能走人工导出路线（CNKI/万方检索"中国科学院高能物理研究所"学位论文，导出后走 `csv_importer`），或改用同所的其他公开页面（见下）。

## 备选路线（待摸排）

1. **高能所研究生教育栏目**（ihep.ac.cn 主站）：各所普遍公开发布"博士学位论文答辩公告/学位授予名单"，公告文本通常含"学生 XXX、导师 YYY"，是静态 HTML，可礼貌低频采集 → 建议下一轮摸排
2. CNKI/万方手工导出 → csv_importer（无反爬问题）
3. WikiData：已覆盖知名学者（李惕碚等），随 wikidata 适配器自动增长

## 经验（适用于其他中科院研究所）

中科院体系 IR 均为 CSpace 平台，部署方普遍关闭 OAI/REST 并加滑动验证码。
摸排下一个中科院研究所时，直接测 `/oai/request?verb=Identify` + 任意详情页即可 1 分钟判定，不必逐一试搜索接口。
