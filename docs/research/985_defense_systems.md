# 985 高校答辩公示系统可抓性调研（2026-10-19）

调研方法：各校研究生院首页 + 公示系统入口实际探测（礼貌抓取，单次 GET）。
判定标准：**可批量** = 单次/少量请求拿到结构化名单（学生+导师+专业），类似中科大 pyxt。

## A 类：系统级公开公示，可直接批量抓取

| 学校 | 入口 | 格式 | 备注 |
|---|---|---|---|
| 中国科学技术大学 | pyxt.ustc.edu.cn/?menu=public_replay | 静态 HTML 大表 | 滚动约半年窗口（~1200 行/次），已入库 1343 边 ✅ |
| 大连理工大学 | dutgs.dlut.edu.cn/gmis/xw/dbgggs.aspx | ASPX 表格 | 只列「今天起」即将答辩者，窗口极小（本次实测 2 人）；需每日 cron 攒数据。字段：学号/姓名/导师/学部/专业/题目/时间/地点 |

（清华/北大确认无公开批量答辩公示，已有数据源覆盖：清华工物系名录 + 高校学位论文库）

## 结论与建议

1. **立即可做：大连理工 GMIS**。半天工作量，窗口只有「今天起」→ cron 需每日运行，
   物理学院（等离子体/光学/凝聚态）每次 0–3 人，半年可攒数百人，且与清华工物系
   （等离子体方向）谱系互补。
2. **答辩公示是稀缺品**：39 所里只有 2 所具有 pyxt 级公开系统。主扩张路径仍是
   教师主页（进行中）+ 高校学位论文库扩源 + academictree 国际快照。
3. 若未来要啃 C 类，优先哈工大（核科学强、公告规范）与西交（核科学 A+），
   但需按院系逐站适配。
